# 🔑 Aplicaciones clave para las operaciones

**Qué son:** sistemas de los que **depende actualmente el éxito**, el funcionamiento diario y la supervivencia de la organización — las **"vacas lecheras"** que dan estabilidad operativa. Es el **dominio tradicional** de los SI/TI.

| | |
|---|---|
| **Fuerzas motrices** | **Mejorar el rendimiento de actividades existentes** (velocidad, exactitud, eficacia, economía); **integrar sistemas y datos** para evitar información errónea y duplicación; **evitar desventajas** e impedir que un riesgo del negocio llegue a ser crítico |
| **Requisitos** | **Soluciones de alta calidad y larga vida**; **gestión eficiente de los datos**; equilibrar costes con beneficios y riesgos mediante **análisis objetivo de alternativas viables** |
| **Estrategia genérica ideal** | [[Monopolio]] (potencialmente restrictiva pero **ideal para reducir riesgos**; calidad a largo plazo) |
| **Justificación de la inversión** | Costes y beneficios financieros **+ riesgo**: la solución más económica puede no ser la más eficiente → **estudio de viabilidad riguroso** (equilibrio coste–beneficio–riesgo) |
| **Prioridad dentro del cuadrante** | La más compleja: combinar **economía + riesgos para el negocio + FCE + mejoras de infraestructura** contra costo y recursos |
| **Ejemplos** | Facturación, control de stock, costo de productos, base de datos de personal, cuentas por pagar |
