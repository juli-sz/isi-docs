# 🎯 Aplicaciones estratégicas

**Qué son:** aplicaciones **críticas para ejecutar la estrategia futura** del negocio y asegurar el éxito a largo plazo. Aportan valor diferencial directo: buscan **obtener y mantener ventajas competitivas** o alcanzar [[Factores Críticos de Éxito (Rockart)|FCE]].

| | |
|---|---|
| **Enfoque de gestión** | **Orientación al negocio**: para ser estratégica, debe relacionarse claramente con los **FCE** derivados de los objetivos |
| **Fuerzas motrices** | **Necesidades del mercado y presiones competitivas** (desde el exterior: clientes, proveedores); objetivos empresariales y visión de la dirección |
| **Requisitos** | **Desarrollo rápido** para concretar los beneficios; **solución flexible** adaptable a los cambios del entorno; enlace directo con una **iniciativa de negocio** asociada |
| **Estrategia genérica ideal** | [[Planificación centralizada]] |
| **Justificación de la inversión** | Estimar costes y beneficios hasta donde se pueda, pero las razones principales quedan **intangibles** (FCE) → no se resuelve con un VAN detallado. Éxito = suerte + juicio directivo + buena gestión |
| **Prioridad dentro del cuadrante** | Mayor **contribución a los objetivos** (tabla de decisión con FCE) usando menos recursos |
| **Ejemplos** | Comercio electrónico, ERP, análisis de mercado y predicción de ventas, análisis de beneficios de productos |
