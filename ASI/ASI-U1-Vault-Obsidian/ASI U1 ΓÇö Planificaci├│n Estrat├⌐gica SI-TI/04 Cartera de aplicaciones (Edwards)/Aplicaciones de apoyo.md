# 🧰 Aplicaciones de apoyo

**Qué son:** sistemas **valiosos pero no críticos** para el éxito (ni actual ni futuro); generalmente estándar/administrativos que mejoran la eficiencia de tareas cotidianas.

| | |
|---|---|
| **Fuerzas motrices** | **Productividad y eficiencia de tareas específicas, ya existentes y localizadas**; **requisitos legales**; uso más eficiente en costos de los fondos y recursos de SI/TI |
| **Requisitos** | **Costo ínfimo** y soluciones a largo plazo → suelen comprarse **paquetes de software estándar** (sacrificando necesidades específicas del usuario); evitar la obsolescencia; **análisis coste-beneficio muy objetivo** |
| **Estrategias genéricas ideales** | [[Recurso escaso]] (ideal: obliga a evaluar resultados antes de gastar) y [[Mercado libre]] (si los usuarios usan sus propios fondos) |
| **Justificación de la inversión** | Mejorar la **eficiencia** → cuantificar y convertir en **argumento financiero**. Es el área con más **software estándar** disponible (aplicaciones genéricas, comunes a todas las industrias) |
| **Prioridad dentro del cuadrante** | La más simple: **mayores beneficios económicos con menos recursos** |
| **Ejemplos** | Contabilidad, presupuestos, nóminas, correo electrónico |
