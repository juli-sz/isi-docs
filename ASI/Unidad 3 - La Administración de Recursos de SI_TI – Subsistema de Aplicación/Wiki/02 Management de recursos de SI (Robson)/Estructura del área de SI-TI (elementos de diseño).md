# Estructura del área de SI/TI — elementos de diseño

> [!quote] Definición (apunte sistematizado, sobre Robson)
> "El **management de los recursos de SI** consiste en **estructurar, organizar y administrar** los elementos **humanos, tecnológicos y procedimentales** del área de sistemas, buscando la **eficacia global** del funcionamiento organizacional."

**Organizar** = ordenar actividades comunes para lograr la eficacia del conjunto:
- Implica **modificar o diseñar la estructura** del área de SI/TI; forma parte de los **planes** (objetivos, actividades, recursos).
- El resultado es una **estructura organizativa**: jerarquías y departamentos, pero también **procesos de coordinación, conducción y uso de tecnologías**.
- Objetivo final: **efecto sinérgico**.

## ¿De qué depende la estructura?
1. **Objetivos y decisiones** (grado de **delegación o retención** de autoridad).
2. **Actividades** del área.
3. **Distribución de los recursos** (personal, presupuesto, infraestructura).
4. **Red de comunicaciones** (cómo fluye la información).

Cada empresa, según estrategia, entorno, tecnología, fortalezas y debilidades, tendrá **una forma distinta** (organigramas funcionales, matriciales o por proyectos).

## Elementos clave

| Elemento | Pregunta | Concepto |
|---|---|---|
| **Especialización del trabajo** | ¿En qué grado se subdividen las tareas? | Tareas integradas o separadas (ej. análisis y desarrollo juntos o no) |
| **Departamentalización** | ¿Cómo se agrupan personas y tareas? | Por función, producto, cliente, etc. |
| **Cadena de mando** | ¿A quién informan? | Niveles jerárquicos y líneas de autoridad |
| **Tramo de control** | ¿Cuántos dependen de un gerente? | Alcance de la supervisión |
| **Centralización / descentralización** | ¿Dónde se toman las decisiones? | Concentradas o distribuidas |
| **Formalización** | ¿Qué grado de estandarización? | Reglas, procedimientos y documentación |

## Qué centralizar y qué descentralizar

| **A descentralizar** | **A centralizar** |
|---|---|
| Producción (desarrollo de aplicaciones bajo el subgerente de desarrollo) | Manejo de fondos |
| Organización interna y tareas operativas | Objetivos estratégicos |
| | Inversiones y presupuestos |
| | Designación de cuadros superiores (el gerente de sistemas lo designa la gerencia general) |
| | Definición de niveles salariales |

> [!tip] Clave
> **El alineamiento** (U1) proporciona el marco para tomar las decisiones sobre el RUO.

> [!tip] Cruce con aplicación de RRHH
> Estos elementos son el "organigrama" donde se ubican los **cargos**: la cadena de mando y el tramo de control definen la **responsabilidad** y la **autoridad** de cada cargo → [[Diseño de cargos]].
